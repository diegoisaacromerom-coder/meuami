    Consultas SQL

    Para las preguntas que las tablas de arriba no alcanzan a responder. El inventario consolidado se carga en un motor de base de datos que corre dentro de este navegador y se interroga con SQL. Los datos no salen de este equipo: no hay servidor al que lleguen.

    El motor pesa alrededor de 8 MB y se descarga la primera vez que lo pidas; después el navegador lo conserva en caché. Esa primera carga necesita conexión, así que conviene prepararlo antes de una sesión de trabajo sin red. Ninguna otra parte del panel ni del sitio público lo descarga, y los datos del inventario nunca salen de este equipo: lo que se descarga es el programa, no se sube la información.
